# DRESS System - User Guide

## Logging In

1. Open the DRESS system URL in your browser
2. Enter your **Username** and **Password**
3. Click **Login**
4. You'll be redirected to your role-specific dashboard

---

## Security Dashboard

### Starting Monitoring
1. Click **Turn On Camera** to begin video feed
2. System automatically detects people and checks dress code
3. Students tap their RFID card to be identified
4. Violations are automatically recorded when detected

### Configuring Schedule
1. Click **Settings** (⚙️) button in the floating menu
2. **System Schedule** section:
   - Check/uncheck days (Monday-Sunday)
   - Set start and end times
3. Click **Save Schedule**
4. System automatically enables/disables during scheduled hours

### Test Mode
1. Toggle **Test Mode** ON
2. Allows detection at all times in camera (overrides schedule restrictions)
3. Toggle OFF when done

### Camera Controls
- **Turn On Camera**: Begin video feed (button changes to "Turn Off Camera" when active)
- **Reset Tracker**: Reset the person tracking system
- **Test Mode**: Toggle test mode on/off
- **Camera Selection**: Choose camera ID from dropdown

### RFID Status
- Shows if RFID card is detected
- Displays student information when card is scanned
- Detection only works when valid card is present

### Logging Out
- Click the **logout icon** in the bottom-right corner (floating menu)

## Dean Dashboard

### Viewing Violations
1. Click **Violations** in the sidebar
2. Violations table shows all violations for your college
3. Use filters to narrow results:
   - **Search**: Search by name, student ID, program, or violation type
   - **From/To**: Select date range (start and end dates)
   - **Program**: Filter by program
4. Status is displayed in the table

### Generating Reports
1. Navigate to **Violations** section in sidebar
2. Scroll down to **Generate Report** section
3. Select **Month** and **Year**
4. Click **Generate** button
5. Report opens in a new window/tab

### Student Management
1. Click **Students** in the sidebar
2. Use search to find students by name, student ID, email, program, or RFID UID
3. Filter by program if needed
4. View student information in the table
5. Click **Edit** to modify student details
6. Click **Delete** to remove a student
7. Click **Add Student** to add a new student

### Sidebar Navigation
- **Overview**: View summary metrics
- **Statistics**: View charts and analytics
- **Violations**: View violation records and generate reports
- **Students**: View and manage students
- **Notifications**: View notifications
- **Settings**: Access settings

### Logging Out
- Click the **Logout** button in the sidebar

## Quick Reference

### Status Indicators (Security Dashboard)
- **Camera Status**: Active/Inactive
- **RFID Status**: Active/Inactive
- **Detection Mode**: RFID-Triggered/Test
- **Schedule Status**: Shows if within scheduled hours

### Violation Statuses (Dean, OSAS, Guidance Dashboards)
- **Pending**: Awaiting resolution
- **Resolved**: Violation addressed

### Strike System
- **1st Offense**: Warning
- **2nd Offense**: 5-day suspension
- **3rd Offense**: 2-week to 1-month suspension

### System Behavior
- **Offline Operation**: System works offline, violations recorded, emails queued
- **Automatic Emails**: Sent when violation detected (queued if offline)
- **Follow-up Emails**: Sent automatically after 3 days if violation still pending
- **Schedule Control**: RFID and detection only active during scheduled hours (unless test mode)
